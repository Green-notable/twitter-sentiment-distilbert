NLP情感分类项目，基于DistilBERT的Twitter文本情感分析
# Twitter Text Sentiment Classification with DistilBERT

## 项目简介
针对Twitter短文本口语化、情绪模糊、样本不均衡的特点，完成从数据探索、清洗建模、模型对比到误差归因的全链路NLP数据分析项目。

## 技术栈
- Python
- Hugging Face Transformers (DistilBERT)
- Pandas, NumPy
- Matplotlib, Seaborn

## 项目亮点
- 对比传统机器学习与DistilBERT微调方案，微调模型准确率达92%，较传统方法提升近30个百分点
- 运用混淆矩阵、损失排序定位误判原因，沉淀可复用的NLP错误分析方法论
- 建立「数据→模型→误差归因→结论建议」的完整分析闭环
